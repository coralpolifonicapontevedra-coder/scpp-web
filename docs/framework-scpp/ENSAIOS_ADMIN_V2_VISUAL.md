# Ensaios Admin v2 — criterio visual

Data: 28/08/2026

A presentación de Administración → Ensaios v2 debe seguir o mesmo patrón visual que Administración → Concertos.

Regras:
- separar sempre etiqueta e valor en bloques distintos;
- nunca concatenar textos como `Datadomingo...` ou `0 obras0 asistencias`;
- usar unha grella de tarxeta equivalente a Concertos: data / información principal / estado / accións;
- conservar a mesma xerarquía tipográfica, bordos, espazados e botóns;
- en móbil, apilar a grella mantendo as etiquetas por riba dos valores;
- manter a API e permisos sen cambios durante este axuste visual.
