# Ensaios Admin v2 — Xestión

Data: 28/08/2026

A v2 debe incorporar un botón `Xestionar` equivalente ao de Administración → Concertos.

Primeira fase:
- abrir un diálogo de xestión do ensaio;
- mostrar coralistas agrupados por corda;
- permitir marcar `Asiste`, `Non asiste` e `Non asiste con xustificación`;
- permitir indicar motivo/xustificación;
- gardar sobre `AsistenciasEnsaios` mediante as accións existentes de Ensaios;
- recargar os contadores tras gardar.

Fases seguintes:
- Obras a ensaiar;
- carga desde programa;
- análise de asistencias;
- finalización do ensaio.

O deseño do diálogo debe seguir o patrón visual de `Xestionar` en Concertos.
